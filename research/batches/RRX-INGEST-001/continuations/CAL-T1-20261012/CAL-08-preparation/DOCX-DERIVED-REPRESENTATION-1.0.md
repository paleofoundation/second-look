# PASTIS supplementary Word document representation contract 1.0

This prospective contract permits only preparation of the received PASTIS supplement for source review. A matching GP is required before materialization, rendering or inspection. It does not authorize a scientific review, acceptance, canonical import or release.

Preserve the exact Europe PMC archive and every member identity. Materialize only the named `ALZ-18-2393-s001.docx` member after verifying the entire bounded archive inventory, hashes, CRCs and path uniqueness. Retain the original Word bytes unchanged outside Git and public assets. Compare the archive's four JPEGs with the separately received images; GIFs are alternate thumbnails, not extra experiments. File association remains subject to source review.

Use the bundled Documents renderer and bundled LibreOffice, never the user's desktop installation. Save a new derived PDF and page PNGs in the ignored private source directory, with source hash, renderer hash/version, command, output hashes and physical page count. No editing, style correction, field rewriting, redline acceptance or scientific transcription is permitted during conversion. A failed conversion is a preparation hold.

Before source readiness, inspect every rendered page for clipping, missing content, table alignment, symbols and legibility. Compare document XML paragraph and cell text against the PDF text; enumerate native body blocks, tables, text-bearing headers/footers/footnotes/endnotes, drawings and embedded objects. Record all tracked changes, comments, external links and fields rather than silently suppressing them. Unrepresented substantive material holds readiness. A mechanical text match is useful evidence but is not visual or scientific acceptance.

The derived PDF has its own asset identity and SHA. Its locators are physical PDF pages, explicitly labeled as derived from the pinned original Word asset. Original Word page numbering is not inferred. A versioned derivation manifest binds the original DOCX, parent archive, rendering controls, all output hashes, native-content coverage and visual verification. The original DOCX is preserved as the authoritative asset in that manifest and portable source map; the assigned PDF is its verified reading representation, not a publisher PDF. Include the manifest as a required JSON inspection asset. Review all derived PDF pages and the manifest under a fresh source-review GP. All scientific claims must link to that representation and retain its lineage to the original source.

The frozen full-review v1 PDF/JSON locator contracts remain unchanged. This contract supplies a separate, prospectively verified representation; it does not relabel Word bytes as PDF or discard the unsupported original. Source readiness requires integrator disposition of conversion discrepancies. Independent scientific audit must also verify original-to-derived content coverage, source identity and every consequential table/figure. Any original or derived byte change invalidates downstream readiness, reviews and acceptance.
