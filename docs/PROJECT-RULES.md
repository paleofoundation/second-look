## 2026-11-05: citation gate retries and explicit non-DOI sources

Source: citation-gate failures on pull requests 44, 45, 46, and 48 through 52 after GitHub Actions billing was restored, 5 November 2026. Scope: `scripts/check-citation-gate.mjs` and its unit tests. This does not lower the DOI rule for ordinary scholarly articles, and it does not by itself approve the open fills.

A Crossref or Europe PMC HTTP 429 is retried with exponential backoff and the Retry-After header, then cached for the rest of the job. If the rate limit remains after those retries, that DOI or PubMed id is not counted as a failed citation. After one identifier stays rate limited, later identifiers in that run get one more attempt and then the same non-failure, so a burst does not turn into a long series of identical waits. A transport failure or HTTP 500, 502, 503, or 504 is retried the same way and still fails when it persists. HTTP 404, a Crossref retraction, withdrawal, or removal notice, a DOI that is not in `research/deposits/**/MANIFEST.csv` or `research/corpus/**`, and a source with no DOI and no explicit non-DOI type still fail.

A cited source may omit a DOI when it is explicitly typed and has a public http(s) URL. The types are `regulatory-label` and `agency-page`. Existing `sourceTier` values `official_label` and `regulatory_guidance` are those types. A journal article that has no DOI may be typed `no-doi-article` only with a PubMed id that is already in the deposit or corpus files and that Europe PMC reports with no DOI. If Europe PMC reports a DOI, the source fails until that DOI is cited and checked. A URL on an FDA, DailyMed, or other agency host does not by itself make a source a non-DOI source. A DOI on the source is still checked even when a non-DOI type is also set.
